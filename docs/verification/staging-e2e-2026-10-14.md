## 3. Backup rehearsal — findings

- **Finding B-1 (blocking for automated backups):** the staging *app* DB user
  cannot take a consistent dump — `pg_dump` fails with `permission denied for
  table _prisma_migrations`. The rehearsal succeeded using the container
  superuser (`pg_dump -U "$POSTGRES_USER"` inside the postgres container).
- **Finding B-2 (positive):** restore ordering validated — globals (roles) must
  be applied **before** `pg_restore`, otherwise all GRANT statements fail on the
  missing staging roles. The documented recovery procedure already mandates this.
- Data/DDL restore is byte-faithful at current scale (row counts identical).
